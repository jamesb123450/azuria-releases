Development preview

Vanilla and Fabric launching, Microsoft sign-in and automatic updates are available in current Windows builds. See the release notes for your version.

Before you install

  • A Windows x64 PC with Microsoft Edge WebView2 available.
  • A Microsoft account that owns Minecraft Java Edition, plus internet access and free disk space for the first game installation.
  • Only download builds from Azuria’s GitHub release page.
  • Update signatures verify Azuria updates. Windows publisher signing is separate; development installers are not Authenticode signed.
Installation help

Install once.
Update in the app.

  1. 01

    Download the installer

    Use the Windows x64 installer above. Other platforms are not available yet.

  2. 02

    Install and open Azuria

    Follow the installer, then create an instance to explore version, loader and icon settings.

  3. 03

    Keep it up to date

    Azuria checks and downloads signed updates at startup. Restart to install, or choose Later and return to Settings → Updates.
