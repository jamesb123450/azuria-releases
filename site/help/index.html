Current capabilities

Azuria is a Windows-first Minecraft Java launcher in development. Current builds support Vanilla and Fabric launching, with Minecraft Java ownership verified through Microsoft sign-in.

Installation

What do I need?+

A Windows x64 PC with Microsoft Edge WebView2 available. The current release is a development preview. There are no supported macOS, Linux or ARM64 builds.

Why might Windows show an unfamiliar publisher warning?+

Azuria’s development installers are not Windows Authenticode signed. The signature used by the in-app updater is a separate mechanism. Verify that you downloaded the installer from the project’s GitHub release page and make your own trust decision before running it.

Can I use the browser preview to play?+

No. The browser preview is for trying the interface. Its local data is separate from the installed launcher, and it does not support account sign-in, desktop updates or game launching.

Updates

How do I update?+

Azuria checks at startup and downloads signed updates automatically. When ready, a restart countdown installs the update. Choose Later to postpone, then use Settings → Updates to restart when convenient. Active games block installation.

What is the .sig file?+

It is the installer’s update signature, not a private signing key. The updater checks signed downloads against the public key included in the app. You normally do not need to handle the signature file yourself.

What if an update fails?+

Check your connection and retry from Settings. If needed, use the latest installer from the project’s GitHub release page. Include the error and your Azuria version when reporting a problem; do not include account tokens.

Microsoft sign-in

Azuria opens your default browser for Microsoft sign-in. The native app then checks Xbox and Minecraft Services access. Sign in with a personal Microsoft account that owns Minecraft Java Edition.

Why does Minecraft Services deny Azuria access?+

Use the latest Azuria release and an account that owns Minecraft Java Edition, then try reconnecting. If access is still denied, report the exact error and launcher version. A generic HTTP 403 alone does not identify the cause; never include account tokens in a report.

Which account should I use?+

A personal Microsoft account with Minecraft Java Edition access. An organisation owning the app registration does not mean players should use a work or school account.

What does signing out remove?+

Signing out removes the saved Azuria account from Windows Credential Manager. Your browser may stay signed in to Microsoft. Failed or cancelled account switches preserve the previously saved account.

Privacy & storage

Read the privacy policy for website hosting, account data and support information.

This website has no accounts. Optional Google Analytics is used only when configured and you accept analytics in Cookie settings. Fonts and screenshots are served with the site. GitHub hosts the site and installer downloads and processes requests under its own policies.

The desktop launcher stores instance settings locally. Refresh credentials use Windows Credential Manager; account tokens are handled in native code. The current app does not collect analytics or upload logs.

Removing an instance keeps its files in local trash. Duplicating an instance can copy settings alone or include its local files. There is not yet a restore interface; read the recovery instructions before attempting manual recovery.

Storage & recovery instructions

Something not right?

Check the release notes first, then open an issue on GitHub. Include your Azuria version, Windows version, what you expected and the steps that caused the problem. Remove personal details from screenshots and never include account tokens or credentials.

Report an issue

Public installers, release notes and support issues are available on GitHub. Launcher source is maintained separately.
