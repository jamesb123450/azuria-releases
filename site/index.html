Before you download

Platform support, updates and what works today.

Can I play Minecraft through Azuria yet?+

Yes. Current Windows builds prepare and launch Vanilla and Fabric instances using a verified Minecraft Java account. Other loaders and live modpack installation are still in development.

Which platforms are supported?+

Current builds support Windows x64. macOS, Linux and ARM64 builds are not available.

How do updates work?+

Azuria checks for signed updates at startup and downloads them automatically. A restart countdown installs the update; choose Later to postpone. Updates wait while Minecraft is running.
