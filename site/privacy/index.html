Privacy policy

Last updated: 18 October 2026. This policy covers this website and the current Azuria development launcher.

The projectWebsite dataLauncher dataSupportYour choices

Who runs Azuria

Azuria is an independent project maintained by jamesb123450 on GitHub. It is not operated by Microsoft or Mojang. The contact page lists the available ways to reach the project.

When you visit this website

This website does not create accounts, set its own cookies, store preferences in your browser or include analytics, advertising trackers or embedded social feeds. Fonts and images are hosted with the website.

GitHub Pages hosts the website and GitHub Releases hosts downloads. GitHub receives technical request information, such as your IP address and browser details, to provide and secure those services. Its handling, retention and international processing of that information are described in the GitHub Privacy Statement.

When a page opens, your browser requests the latest published release from GitHub’s public API. This sends ordinary connection information to GitHub; it does not send launcher settings, account details or files. If the request fails, the last built release information remains visible and the latest-release link still works.

When you use the launcher

The launcher stores instance settings, preferences and account profile information locally on your computer. Microsoft refresh credentials are saved through Windows Credential Manager. Authentication tokens are handled by the native launcher rather than collected by this website.

Choosing Microsoft sign-in connects to Microsoft, Xbox and Minecraft Services for authentication, entitlement checks and profile information. Azuria does not ask you to enter your Microsoft password on this website. Microsoft processes those requests under its Privacy Statement.

The current launcher checks GitHub for updates and contacts version-metadata services when you use relevant version selectors. CurseForge catalogue requests use Azuria’s Cloudflare-hosted content service, which receives search terms and project/file identifiers to forward to CurseForge. The publisher’s API credential remains server-side. Cloudflare processes normal request metadata and applies rate limits; Microsoft tokens and game logs are not sent to that service. Those providers receive normal network request information. The current app does not include analytics collection or automatically upload your logs to the project maintainer.

Configured Windows builds support optional Discord Rich Presence. While Minecraft runs, Azuria sends generic Playing Minecraft activity and its start time to the local Discord client. Account, instance, world and server names are not included. Disable this in Settings → Behaviour or through Discord’s activity controls.

Information you choose to share

If you create a GitHub issue, the maintainer can see your GitHub username and anything you submit. Issues are public. Share only the details needed to investigate the problem. Never post passwords, tokens, private logs or sensitive personal information.

Support information is used to answer requests, investigate faults and maintain the project. The project’s interest in providing support is the reason for this processing. Public issues and their history can remain available until removed through GitHub’s controls; copies may exist outside the project’s control. The contact page has no active message form and does not collect or send form entries.

Your choices and rights

You can use the website without signing in. To remove saved launcher account credentials, sign out in Settings. Local preferences and instance files remain on your device until you remove them; deleting an instance may retain files in local trash. See the storage and recovery instructions before removing files.

Depending on applicable law, you may have rights to access, correct, delete or restrict the use of personal information, or to object to processing. For information held by GitHub or Microsoft, use that provider’s privacy request process. For information shared directly with the Azuria maintainer, use the contact page to request a suitable route without publishing sensitive details. UK users can also contact the Information Commissioner’s Office.

Changes to this policy will be published here with a revised date. New collection or integrations will be described before they are introduced.
